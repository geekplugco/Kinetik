# KINETIK — Demo Narratives

These are the launch-ready narratives for Theme Store presets and demo content. They translate the originality manifesto into concrete page sequences, product grouping, image direction, and interaction moments.

## 1. Field System / Storm Commute

**Use case:** technical apparel, bags, footwear, commuter gear.

**Story:** a complete kit moves from rain commute to field work to late return. The merchant is selling a system, not isolated products.

**Homepage sequence:** hero with drop signal -> launch telemetry -> new arrivals -> category entry -> hero product -> build-your-kit -> material proof -> route map -> shoppable lookbook -> field trust -> journal -> drop access newsletter.

**Copy rhythm:** short mono labels, direct product proof, no lifestyle filler. Use concrete conditions: platform rain, field load, low-light return.

**Image requirements:** wide hero with real garments visible; route/detail shots showing shell, sling, base layer, closures; no blurred atmospheric-only imagery.

**Merchandising logic:** new arrivals first, then kit builder, then one hero SKU, then category discovery. Upsells should complete roles: shell, base, carry, audio, cap.

**Interaction moments:** hero mask reveal; route-map hairline readout; shoppable lookbook hotspots; product cards in technical scan mode; cart drawer complete-the-kit rail.

## 2. Carbon Capsule / Night Utility

**Use case:** techwear, streetwear, premium accessories, audio.

**Story:** a dark, high-contrast capsule built around night movement and signal clarity.

**Homepage sequence:** overlay hero on Carbon scheme -> marquee with material claims -> featured collection in commerce-dense mode -> lookbook editorial grid -> material scan/detail modules -> testimonials as field reports -> newsletter as access list.

**Copy rhythm:** clipped and operational: "low light", "sealed carry", "audio tucked", "reflective readout". Avoid cyber cliches and fake scarcity.

**Image requirements:** high-contrast product-visible night shots, reflective details, hardware closeups, real product color variation.

**Merchandising logic:** fewer products per rail, strong badges, swatches visible, quick add prominent on mobile. Cart upsell should attach audio/carry items to apparel.

**Interaction moments:** technical scan overlays on cards; hard wipe image transitions; modal/drawer motion must be clean and tokenized.

## 3. Sand Expedition / Warm Field Kit

**Use case:** outdoor apparel, lifestyle gear, travel accessories, home/utility brands that need softer warmth without losing structure.

**Story:** a warm field kit for long travel days: breathable layers, durable carry, repairable details.

**Homepage sequence:** split hero with tactile image -> collection list by role -> route map as day plan -> image-with-text material story -> build-your-kit -> proof/logo strip -> journal -> newsletter.

**Copy rhythm:** quieter and warmer, but still specific. Use material, care, repair, and endurance language instead of luxury adjectives.

**Image requirements:** daylight product shots, packable layers, hands using hardware, fabric texture. Background can be warm but product must stay inspectable.

**Merchandising logic:** group by role and condition, not gender. Use product-card editorial mode for campaign pages and technical mode for collections.

**Interaction moments:** gentle reveal timing, no bounce; captions behave like field notes; hover states expose proof without hiding the product.

## Shared acceptance rules

- Every demo section has a shopping or proof purpose.
- Presets must be reproducible from Shopify default settings and theme editor controls.
- Product, collection, and cart flows must reinforce the same campaign story.
- No fake urgency, fake social proof, copied benchmark layout, or decorative-only motion.
