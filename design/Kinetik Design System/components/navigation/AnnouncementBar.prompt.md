Thin uppercase-mono promo strip that sits above the header. One message or an auto-rotating set.

```jsx
<AnnouncementBar>Free 24h shipping over $200 · 60-day returns</AnnouncementBar>
<AnnouncementBar tone="volt" messages={['SS26 drop live now', 'Members get early access']} />
```

Keep copy to one tracked line. Use `tone="volt"` sparingly — only for an active drop.
