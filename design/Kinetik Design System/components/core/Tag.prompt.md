Small mono uppercase label for sale flags, status, and spec chips. `sale` is volt and is the only colored tag — keep it for discounts.

```jsx
<Tag tone="sale">−20%</Tag>
<Tag tone="solid">New Drop</Tag>
<Tag tone="outline">Gore-Tex 3L</Tag>
<Tag tone="muted">Sold Out</Tag>
```

Default `square`; use `shape="pill"` only for filter chips.
