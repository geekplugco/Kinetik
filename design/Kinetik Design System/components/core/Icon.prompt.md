Line icon set — 24px Lucide-style glyphs, 1.75 stroke, `currentColor`. Use anywhere you need an icon; it inherits the surrounding text color and never carries its own.

```jsx
<Icon name="bag" size={20} />
<Icon name="arrowUpRight" size={16} strokeWidth={2} />
```

Names: search, bag, menu, close, chevronDown, chevronRight, arrowRight, arrowUpRight, plus, minus, heart, check, filter, user, play, star, package, trash, shield. `play` is the only filled glyph. Size to match the type beside it (16 next to labels, 20 default, 24 in nav).
